# Project: Alphalink switchboard landing campaign (2026 design)

A **separate project** from the earlier `alphalink-electrical` demo. That one used the old site
look (navy + circuit board). This one is built on the approved 2026 landing-page design system
(warm paper, ink, yellow brush marks, documentary photos, handwritten asides).

**Landing page:** https://www.alphalinkelectrical.com.au/switchboard-upgrade-landing/
**Goal:** switchboard quote requests from Melbourne's south-east.
**Phase now:** discovery + asset/workflow options. *No ads yet* (by request).

## Files
| File | What |
|---|---|
| `research.md` | Landing page teardown, 2026 design tokens, claims ledger delta, asset audit |
| `brand.json` | 2026 design system as studio tokens (Figtree / Lato / Gochi Hand, paper/ink/yellow) |
| `assets.manifest.json` | 30 approved assets with source, role and quality notes (raw files git-ignored) |
| `WORKFLOW-OPTIONS.md` | How to produce assets and motion for this campaign: options, tools, costs |
| `ads/` | empty until the ad phase starts |

## Get the assets locally
```bash
cd studio && npm run assets alphalink-switchboard-landing
```
